# Swift Mac Prototype

This directory preserves Brain Cache's first SwiftUI and SwiftData Mac prototype. It is retained for reference while the primary Mac application lives in `apps/mac` as Tauri + React.

The prototype is not part of the current build or verification path. The native iPhone app, its `Cache a Thought` App Intent, Lock Screen WidgetKit extension, and Share Sheet extension live under `apps/ios`, using `ARCHITECTURE.md` as the contract rather than extending this Mac prototype.
